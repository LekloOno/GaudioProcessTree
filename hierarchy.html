 ▼CAUD_SoundDefines the base abstraction and implementation of AUD_ISound sound processing tree nodes.

Such tree are composed of module nodes (non-leaf) that encapsulate further nodes, until eventually reaching stream player leafs.
The module nodes provide specific interfaces for various redundant processing operation like fading, layering, randomization, etc.
The stream nodes bind this tree to concrete Godot AudioStreamPlayers, in a generic manner so that any "spatialness" can be relevant to the same processing tree
 ▼CAUD_ModuleA sound module is a non-leaf node in an AUD_Sound processing tree.
It encapsulates one or multiple other AUD_Sound - its children - and provides interractions with them through its AUD_Sound and AUD_Module implementation
 CAUD_FaderFades in and out the VolumeDb of a child AUD_Sound by respectively calling Play() and Stop()
 CAUD_LayeredSoundPlays and control multiple children sound as one
 ▼CAUD_RandomSoundPlays a random sound on a given player, with pitchScale randomization.
It does not play a random AUD_Sound ! Its child must be an AUD_StreamPlayer.
Otherwize, that would imply the use of many distinct players for such a common pattern
 CAUD_ParallelSoundSpecialization of AUD_RandomSound that runs each new stream Play on a parallel channel.

Modification to its relative volumeDb and pitchScale still applies to all channels, but relatively to their own initial volumeDb and pitchScale.
This is the default behavior for volumeDb, but modifying the pitch scale of a player usually don't affect polyphonic stream.
The node provides a way to achieve it while maintaining independant base pitch.

Setting the Stream of an AudioStreamPlayer stops all its currently playing sounds. AUD_RandomSound would suffer from this in cases where we need to repeatedly play.
AUD_ParallelSound is thus also relevant if avoiding this issue is necessary
 ▼CAUD_StreamPlayerA Stream Player is a leaf node in an AUD_Sound processing tree.
It binds the tree branch to a concrete Godot AudioStreamPlayer by wrapping it under a generic interface so that any kind of AudioStreamPlayer (simple, 2D, 3D) can be used.

It is not necessary for the Godot AudioStreamPlayer to be a child of the AUD_StreamPlayer, and child aren't auto-referenced but should be manually assigned in the inspector. It is intentionnal, not to break possible Node3D/Node2D required spatial hierarchy, since AUD_Sound only extends Node.
You can thus place an AudioStreamPlayer2D/3D wherever you want to be correctly spatially-parented
